# 📐 三角比・三角関数 計算練習 (Trigonometric Functions Practice)

高校数学の「三角比・三角関数」を、スマホやPCでサクサク反復練習できる完全無料のWebアプリです。
ランダムに出題される問題に答えながら、基礎から応用までしっかりと定着させることができます。

## ✨ 特徴 (Features)

* **豊富な出題テーマ**: 基礎の三角比から、加法定理、合成、積和・和積の公式まで幅広く対応しています。
* **無限に練習可能**: 数値や図形がランダムに生成されるため、何度でも新鮮な問題に挑戦できます。
* **丁寧な解説付き**: 間違えてしまった場合でも、途中式や図解（単位円・三角形など）、使用する公式が解説としてすぐに表示されます。
* **美しい数式表示**: KaTeX を利用し、分母分子やルートなどの数式を綺麗に表示します。
* **便利な学習サポート機能**:
  * 📖 **公式チートシート**: 忘れてしまった公式をいつでも確認できるまとめ表を搭載。
  * 🔄 **角度の単位切替**: 「度数法 (°)」「弧度法 (π)」「両方」から好みの設定を選べます。
  * 🌙 **ダークモード対応**: 目に優しいダークテーマにワンタップで切り替え可能です。
* **サクサク進めるUI**: 
  * スマホでの操作に最適化（誤タップ防止・スクロール追従ボタン等）。
  * PCでは「1 / 2 / 3」キーで解答、「Enter / Space」キーで次の問題へ進めるショートカットを搭載。

## 📚 収録テーマ (Topics)

### 数学I（三角比）
* 直角三角形の定義
* 有名角の三角比
* 三角比の相互関係（$\sin^2\theta + \cos^2\theta = 1$ など）
* 三角方程式・不等式
* 正弦定理・余弦定理
* 三角形の面積

### 数学II（三角関数）
* 加法定理
* 2倍角・3倍角の公式
* **半角の公式**
* **三角関数の合成**
* 積和・和積の公式
* マイナー角（15°, 18°, 36°, 72° など）
* 🎲 **総合ランダム演習**

## 🚀 使い方 (Usage)

このアプリは HTML/CSS/JavaScript の **1ファイルのみ** で構成されているため、特別なインストールやビルド環境は一切不要です。

1. 本リポジトリの `index.html` をダウンロードします。
2. お使いのWebブラウザ（Chrome, Safari, Edgeなど）で `index.html` を開くだけで、すぐにプレイできます。

> **💡 Tips:** 
> GitHub Pages（または Vercel, Netlify など）にデプロイすれば、URLを共有するだけで誰でもスマホからアクセスできるようになります。
