# trigonometric_functions_JP

# 📐 三角比・三角関数 計算練習 
高校数学の「三角比・三角関数」を、スマホやPCでサクサク反復練習できるWebサイトです。
ランダムに出題される問題に答えながら、基礎から応用までしっかりと定着させることができます。

## ✨ 特徴 (Features)

- **豊富な出題テーマ**: 基礎の三角比から、加法定理、積和・和積の公式まで幅広く対応。
- **無限に練習可能**: 数値や図形がランダムに生成されるため、何度でも新鮮な問題に挑戦できます。
- **丁寧な解説付き**: 間違えてしまった場合でも、途中式や図解（単位円など）、使用する公式が解説として表示されます。
- **美しい数式表示**: `KaTeX` を利用し、分母分子やルートなどの数式を綺麗に表示します。
- **サクサク進めるUI**: スマホでも押しやすい選択肢ボタンと、PCなら「Enterキー」で次の問題へ進めるショートカットを搭載。

## 📚 収録テーマ (Topics)

- 三角比の定義（直角三角形）
- 相互関係 ($\sin^2\theta + \cos^2\theta = 1$ など)
- 有名角（$30^\circ, 45^\circ, 60^\circ$ など）
- 三角方程式
- 正弦定理・余弦定理
- 三角形の面積
- 加法定理
- 2倍角・3倍角の公式
- 積和・和積の公式
- マイナー角（$15^\circ, 18^\circ, 36^\circ, 72^\circ$ など）

## 🚀 使い方 (Usage)

このアプリは HTML/CSS/JavaScript の1ファイルで構成されているため、特別なインストールは不要です。

1. 本リポジトリの `index.html` をダウンロードします。
2. お使いのWebブラウザ（Chrome, Safari, Edgeなど）で `index.html` を開くだけですぐにプレイできます。

*(※GitHub Pagesを設定すれば、URLを共有するだけで誰でもアクセスできるようになります)*

## 🛠️ 技術スタック (Tech Stack)

- **HTML5 / CSS3**: シンプルで目に優しいノート風のUIデザイン。
- **Vanilla JavaScript**: フレームワーク非依存で、軽量かつ高速な動作。
- **SVG**: 直角三角形や単位円などの図形を動的に描画。
- **KaTeX**: 高速な数式レンダリングライブラリ（CDN経由で読み込み）。
